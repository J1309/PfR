# DSSSB TGT Computer Science (Post Code 41/26) — Learn & CBT Studio

Offline-first preparation platform built specifically for **DSSSB Advertisement No. 03/2026 — Trained Graduate Teacher (Computer Science), Post Code 41/26** (675 vacancies, 416 UR).

## Sections

1. **📚 Learn Hub (`view-learn`):**
   - Complete structured study notes for all **5 Section A subjects** (GA, Reasoning, Math, Hindi, English) and all **10 Section B modules** covering all **32 official technical/BCA topics** (including Computer Graphics, XML/DTD, .NET, Mobile Computing, E-Commerce, Financial Accounting, Business Economics, MIS, Statistics, Interpolation, Physics) and all **10 official B.Ed. Pedagogy modules**.
   - Real-time global concept search and studied-module progress tracking.
2. **🎯 Topic Practice (`view-practice`):**
   - **300 unbiased MCQs** (100 Section A + 200 Section B) with balanced option lengths and runtime option shuffling so answers are never obvious.
   - Instant feedback, explanations, accuracy tracking, and keyboard shortcuts (`1–4`, `N/P`, `S`).
3. **⚡ DSSSB CBT Test Simulator (`view-test`):**
   - Full 200-Question Mock (120 mins), Section A (100 Qs), Section B (100 Qs), and 40-Q Speed Test.
   - Authentic **DSSSB 20-Question Section Lockout** toggle, `+1.00 / −0.25` negative marking, mandatory **40% UR Section-B qualifying check**, historical cutoff comparison (`91/20: 123.93`, `39/22: 122.64`), and full post-test solution review.
4. **⭐ Starred Revision (`view-bookmarks`):**
   - Save tricky questions locally in `localStorage` for quick last-minute review.

## Run Locally
Open `index.html` directly in any browser or serve locally:
```bash
python -m http.server 3000
```
